# Formation GitHub

Formation pratique pour débutants : apprendre les bases de Git et GitHub.

## Prérequis

- Un compte GitHub
- Git installé : [git-scm.com/downloads](https://git-scm.com/downloads)
- Un éditeur de code, par exemple [Visual Studio Code](https://code.visualstudio.com/)

## Déroulé

1. [01-premier-depot](exercices/01-premier-depot/README.md) : créer un dépôt, le cloner, faire un commit et un push
2. [02-modifier-et-pull](exercices/02-modifier-et-pull/README.md) : modifier un fichier sur GitHub et le récupérer avec pull
3. [03-branches-et-pull-requests](exercices/03-branches-et-pull-requests/README.md) : créer une branche, la fusionner et faire une pull request
